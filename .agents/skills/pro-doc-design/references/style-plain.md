# style: "plain"：緑1色の濃淡 × 白地 × ゴシック

ユーザーの指摘を重ねて作った、**装飾を控えめにした既定のスタイル**。
- 「飾りすぎ（cloud）」→ 色は1色の濃淡、雲・回路・影はやめる
- 「飾らなすぎも殺風景」→ 表紙と締めの円弧、左端の縦帯だけ残す
- 「明朝の見出しがキモい」→ 書体は全部ゴシック（Noto Sans JP＋Inter）
- 「色をシンプルにしたら見にくくなった」→ **濃淡の役割を決めて、配置で見せる**（下の「濃淡の使い分け」）

骨組み（帯のタイトル＝目次の項目名、その下に POINT の一文）は cloud と同じ。
見本：`examples/sample_plain.js`。部品：`deck_kit.js` の `style: "plain"`、背景：`scripts/plain_art.js`。

```js
const d = kit.createDeck({ size: "A4", style: "plain", footer: "資料名", title: "資料名" });
```

## 濃淡の使い分け（ここがいちばん大事）
1色だけで見やすくするには、**面の濃さに役割を決め、守る**。

| 段 | 見た目 | 役割 | 1ページに |
|---|---|---|---|
| 1 濃い面 | `accent1`（または `accent4`）＋白い文字 | 主役：結論・引用・最後の答え・一番大事な工程 | **1か所まで** |
| 2 淡い緑の面 | `accent5`＋黒に近い文字 | ひとまとまり：背景・基本の数字・1位の型・POINT | 1〜2か所 |
| 3 灰の面 | `lt2`＋灰の文字 | 比べる相手（「以前のやり方」など）・休憩など重要でないもの | 必要なときだけ |
| 4 白＋細い枠 | 白＋`D3DDD8` の枠 | ふつうの中身（カード・表・行） | いくつでも |

- **文字は黒に近い灰（`text1`）**。緑の文字は「数字・番号・小見出し・参照（→ P.5）」だけ。本文を緑にしない。
- **大きな数字**（71%、411回、約7割）は `accent1` で大きく。これが色の代わりの主役になる。
- 濃い面を並べない。締めの帯（濃い）があるページでは、その上のカードは淡い面にする。
- 「分析」「補足」は濃い面にせず、**白＋左の緑の線（0.07インチ）**にする。
- 順位や番号を丸で囲んで並べない（丸が並ぶと重い）。2位以下は緑の数字だけ。主役（1位）だけ丸。
- 表の見出し行は淡い面（`d.head` が自動）。区分の列は「主役の区分＝濃い／もう一方＝淡い」（`d.cat` は淡い色なら文字を緑にする）。
- 濃い面の上で強調したい語は `accent3`（淡い緑）か白。淡い面・白の上では `accent1`。

## ページの骨組み（A4横）
| 位置（y） | 要素 |
|---|---|
| 左端 | 濃い緑の縦帯（幅0.28）。区分名（はじめに・本題など）を縦書き |
| 0.36 | アイブロウ（緑・11pt・字間3）`"04 ｜ METHOD"` |
| 0.6 | タイトル（ゴシック太字24pt）＝目次の項目名 |
| 1.32 | 細い灰の罫線＋左端だけ短い緑の太線 |
| 1.5〜1.96 | POINT：淡い緑の帯＋左の緑の棒＋太字15pt |
| 2.05〜7.5 | 本文（`d.TOP`〜`d.BOTTOM`）。地は白 |
| 7.77 | 細い罫線＋フッター |

## 部品の違い（cloud との差）
- `cloudCover`：濃い緑の地＋同系色の円弧。`motif` は無視。
- `toc`：色の面を使わず、左に部の名前＋縦線、項目は罫線で区切った行。
- `chips`：淡い緑の面。`callout`：淡い緑の面＋濃いラベル（文字は黒、強調は `accent1`）。
- `timelineBar`：主役（`vary`）だけ濃い緑、決まった予定（`fixed`）は淡い緑、休憩（`rest`）は灰。
- `roadmap`：淡い → 濃いへ段階的に（進むほど濃く）。
- `closingArt`：表紙の円弧を切り抜いた濃い帯。

## 書体
- 全部ゴシック：和文 Noto Sans JP、英数字 Inter。見出しも同じ（`headFont` は指定しない）。
- 明朝はユーザーに不評。使わない。

## 納品前に見る所
- [ ] 濃い面が1ページ2か所以上ないか（締めの帯も1か所に数える）
- [ ] 本文の文字が緑になっていないか
- [ ] 淡い面の上に白い文字、濃い面の上に緑の文字が乗っていないか
- [ ] 主役（大きな数字か濃い面）が各ページで1つに決まっているか
- [ ] 隣り合う帯（POINT と題材など）が同じ見た目で並んでいないか（片方を白＋枠に）
