# style: "plain"：緑1色の濃淡 × 明朝の見出し × 細い罫線

「飾りすぎ。もっとシンプルで、色も同色の濃淡のほうが見やすい」「飾らなすぎも殺風景」という指摘を受けて作った、
**装飾を控えめに保つ**スタイル。決算説明資料（IR）のスライドを参考にした雰囲気（深い緑・白地・明朝の見出し・
数字を大きく・区分ラベル）を取り入れ、雲・回路・影・オレンジの強調はやめた。
骨組み（帯のタイトル＝目次の項目名、その下に POINT の一文）は `style-cloud.md` と同じ。

- 見本：`examples/sample_plain.js`（A4横5ページ）。部品：`deck_kit.js` の `style: "plain"`、背景：`scripts/plain_art.js`
- 既定は plain。`createDeck({ size: "A4", style: "plain", footer: "資料名", title: "資料名" })`

## 方針（足しすぎず、引きすぎない）
1. **色は緑1色。濃淡で役割を分ける**。区別は「濃さ」と「文字ラベル」で行い、色相を増やさない。
2. 飾りは3つだけ：①表紙と締めの帯の同系色の円弧 ②ページ地のごく淡い緑と右下の薄い円弧 ③左端の縦帯（区分名の縦書き）。これ以上足さない。
3. 影は付けない。白いカードは細い枠線（`C9DDD5`）。色面のカードは枠なし。
4. 強調は「一番濃い緑＋太字」「大きな数字」。1ページに1か所。

## 色（パレット `plain`）
| 役割 | 色 | 使う所 |
|---|---|---|
| `C.text1` | `#12372C` 濃い緑 | 本文、表の見出し行、濃い面（分析・引用・締め） |
| `C.text2` | `#52655D` | 説明文、注記 |
| `C.accent4` | `#0B2B21` 最も濃い | 「必須」「まとめ」など最重要の区分 |
| `C.accent1` | `#1F6B52` 濃い | 主役の数字・見出し・主役カードの帯・強調の区分 |
| `C.accent2` | `#4C8573` 中 | 2番目の区分、参照（→ P.5）、ステップ番号 |
| `C.accent3` | `#A9CBBE` 淡い | **濃い面の上の文字**（強調・補助・氏名）。白地の上では文字に使わない |
| `C.accent5` | `#E3EEE9` | POINT の帯、ラベル、主役の淡い地 |
| `C.accent6` | `#8A9C95` | 控えめ（比べる相手）、フッター |
| 面 | `#EEF4F1 → #F8FBF9`（背景画像） | ページの地。カードは白 |

濃い面の上で強調したいとき：`C.accent1` は暗くて見えない。`C.accent3` か白にする（見た目の違いは太さ・大きさで付ける）。

## 文字
- 見出し・表紙タイトル：**BIZ UDPMincho**（Windows 標準。pptx を別のPCで開いても崩れない）。本文：Noto Sans JP＋Inter。
- 大きな数字は `fontFace: d.headFont` で明朝にすると締まる（任意）。

## 部品
`style-cloud.md` の部品（`page` `cloudCover` `toc` `card` `pill` `closingArt` と既存の型）がそのまま使える。違い：
- `cloudCover`：濃い緑の地＋円弧。タイトルは明朝。`motif` は無視される。
- `closingArt`：表紙と同じ円弧の絵を切り抜いた帯（`motif` 無視）。`accent` の2行目は淡い緑。
- `toc`：部の色は濃淡で（例：導入＝`accent2`、本題＝`accent1`、まとめ＝`accent4`）。`accent3` は白字が読めないので使わない。

## よくある失敗
| 症状 | 直し方 |
|---|---|
| 濃い面の上の強調語が見えない | `C.accent1` → `C.accent3` か白 |
| 淡い色のラベルに白い文字 | 淡い色（`accent3`/`accent5`）の上は濃い文字、濃い色の上は白い文字 |
| 殺風景に見える | 飾りを足す前に、主役を1つ大きくし、濃い面（分析・引用）を1つ入れる |
| 区分が濃淡で見分けにくい | 文字ラベル（必須／あると強い）を必ず添える。隣り合う区分は2段以上離した濃さに |
