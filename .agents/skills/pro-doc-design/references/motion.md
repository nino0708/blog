# 動き（画面切り替え・アニメーション）の方針

## 付けるとよい所
- **手順・流れ**（ステップ、判断フロー）：1行ずつ表示すると、話している所と画面が一致する。
- **結論を最後に見せたいとき**：根拠を並べてから、結論の帯を表示する。
- **ページの切り替え**：全ページ同じフェード（0.4秒程度）。区切りがわかり、目が疲れない。

## 付けない所
- 表紙、目次、表だけのページ、写真だけのページ。
- 1ページに5段階を超える表示（クリックが多いと話が止まる）。
- 回転・バウンド・拡大などの派手な効果。文字を1文字ずつ出す効果。
- 配布だけの資料（PDFでは動かない。付けても害はないが、意味もない）。

## ルール
1. 効果はフェードだけ、全ページで統一する。
2. 表示の順番は、話す順番と同じにする。
3. 最終状態（全部表示された状態）が、そのまま完成した1枚になるように作る。
   途中で消える要素や、重ねて入れ替える図は作らない（印刷すると重なって読めない）。
4. 段階表示は、関係する図形をまとめて1段階にする（四角と中の文字と矢印を同時に）。

## 使い方
`deck_kit.js` の図解パターンに `build: true` を付けると、行・カードごとに `b1|`, `b2|` ... の名前が付く。
自分で置く図形は `build: 番号` を付ける（同じ番号は同時に表示）。

```js
d.flowRows(s, rows, { y: 1.3, build: true });         // 行ごとにクリックで表示
d.txt(s, "結論", { ..., build: 4, objectName: "conclusion" });
await d.save("out.pptx", { motion: true });           // フェード切り替え＋段階表示
await d.save("out.pptx", { motion: true, chain: true }); // 1クリックで順番に自動表示
```

既にあるファイルにだけ付ける場合：
```bash
python3 scripts/add_motion.py in.pptx out.pptx                 # 切り替え＋段階表示
python3 scripts/add_motion.py in.pptx out.pptx --no-build      # 切り替えだけ
```

## PowerPointで手作業するときのコツ（ユーザーに案内する用）
- 「変形（Morph）」は、同じ図形が前後のページにあるときに使うと、位置や大きさの変化が滑らかに見える。
  前後のページで変える要素は少なくする。
- アニメーションの順番は「アニメーションウィンドウ」で確認できる。
