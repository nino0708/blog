# 見やすいExcelの規則

ファイル操作の細部（数式の再計算、既存ファイルの編集など）は `anthropic-skills:xlsx` に従う。
ここでは「見た目と構成」の規則だけをまとめる。雛形は `examples/sample_table.py`。

## 構成
- **1シート1目的**：入力（前提の数字）・計算・出力（報告用の表やグラフ）を別のシートに分ける。
- 先頭に「説明」シート：目的、更新日、各シートの役割、色の意味を書く。
- 全シートで列の並びをそろえる（例：A列＝項目、B列＝単位、C列以降＝月）。
- 同じ計算を二か所でしない。値はリンクで参照する。結合セルは使わない（並べ替え・コピーが壊れる）。

## 見た目
- フォントはブック全体で1種類（BIZ UDPゴシック または 游ゴシック）。本文11pt、見出し12〜14pt。
- 行の高さは既定より少し広く（20前後）。列幅は中身に合わせる。
- 罫線は最小限：見出しの下に1本、合計の上に1本、行の区切りは薄いグレーの横線だけ。縦線と格子は使わない。
- 枠線（グリッド線）は非表示にする。
- 見出し行は濃い色の背景に白い太字、または太字＋下線1本。色は1色だけ。
- 文字は左揃え、数値は右揃え、見出しは中央揃え。数値には桁区切り。単位は専用の列か見出しに書く。
- 色の意味を決めて守る：**入力セルは青字**（ユーザーが変えてよい数字）、計算は黒字、別シートの参照は緑字。強調は1色だけ。
- マイナスは「-1,234」か「▲1,234」で統一する。小数点の桁数も列ごとにそろえる。
- 白黒で印刷しても意味が通るように、色だけでなく太字や記号も使う。

## 操作のしやすさ
- 見出し行と項目の列を固定する（ウィンドウ枠の固定）。
- 一覧の表は「テーブル」にする（並べ替え・絞り込みができ、行の追加で書式が続く）。
- 入力できる値が決まっている所は、入力規則（リスト）で選択式にする。
- 印刷設定：A4、横向き、幅を1ページに収める、見出し行を各ページに印刷、ヘッダーに資料名、フッターにページ番号。

## PowerPointと組み合わせるとき
- 数字の正本はExcel。PowerPointには結論と主要な数字だけを載せ、「詳細：○○.xlsx（シート名）」と出典を書く。
- グラフはExcelでデータを整えてから、PowerPointでは `addChart` で作り直す（画像の貼り付けはしない）。
